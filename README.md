## 어떤 서비스인가요?

하루에 있었던 일을 말로 설명할 수 있어도 빈 일기장 앞에서는 무엇부터 쓸지 막막할 수 있습니다. 오늘,그리고는 초등학교 저학년 등 어린 사용자가 하루의 경험과 감정을 표현하고 기록하도록 돕는 웹 서비스입니다.

AI와 나눈 이야기를 일기 초안으로 정리하고, 직접 그린 그림과 AI 4컷 만화를 함께 남깁니다. 일기와 별도로 **우냥이**에게 고민을 이야기할 수도 있습니다. 기록하며 받은 재화로 방을 꾸미고 나무를 키우는 활동을 연결했습니다.

이 저장소는 서비스의 화면과 사용자 흐름을 담당하는 FE이자, 전체 프로젝트를 소개하는 대표 저장소입니다.

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| **AI 대화형 일기** | AI의 질문에 답하며 하루를 돌아보고, 대화에 근거한 일기 초안을 만듭니다. **저장 전 초안을 확인하고, 저장한 뒤 글을 수정**할 수 있습니다. |
| **직접 그리는 그림일기** | 마우스·터치로 그림을 그리고 날씨를 선택해 일기와 함께 저장합니다. 여러 브러시·색상·지우개·되돌리기를 지원하며 달력에서 월과 날짜를 바꿔 지난 글·그림·원본 대화를 봅니다. |
| **AI 4컷 만화** | 일기 원문과 장면 구성을 확인한 뒤 컷별 이미지를 생성합니다. 진행 상태와 결과를 보고 저장한 일기에 연결해 다시 조회합니다. 일부 컷 실패 시 이미 만들어진 결과를 보존합니다. |
| **우냥이 AI 고민상담** | 방의 창문에서 고민과 감정을 나누는 별도 AI 대화를 엽니다. 지난 기록을 확인하고, 진행 중인 상담은 최신 상태를 조회한 뒤 이어 씁니다. 종료된 상담은 읽기만 가능하며, 만료된 기록은 조회·이어쓰기가 제한됩니다. |
| **상점·방 꾸미기** | 코인으로 테마·가구·장식을 구매하고 보유 아이템을 확인합니다. 테마를 적용하고 **가로 화면에서** 가구·장식을 배치할 수 있습니다. 가구·장식 환불도 제공합니다. |
| **나무 성장·물주기** | 그림일기 보상으로 받은 물방울로 나무를 키웁니다. 일반 회원은 물방울 1개로 하루 한 번 물을 주고 성장 단계를 확인합니다. |
| **계정과 개인 기록** | Supabase Auth의 이메일·비밀번호 회원가입·로그인을 사용합니다. BE가 회원과 기록 소유권을 확인해 본인의 일기·그림·만화·상담 기록을 관리합니다. |

우냥이는 고민을 표현하도록 돕는 AI 대화 기능이며, 전문 심리치료나 진단을 제공하는 서비스는 아닙니다. 상담은 생성 후 7일이 지나면 접근이 제한됩니다.

## 이렇게 이용하세요

1. [서비스](https://today-and-near-team22.pages.dev/)에서 회원가입·로그인합니다.
2. 방의 **책장**을 눌러 오늘 있었던 일을 AI와 이야기합니다.
3. **대화 끝내기**를 확인하고 스케치북에서 그림과 날씨를 준비합니다.
4. 일기 원문과 4컷 장면을 확인합니다. 장면을 확인하고 완성하면 만화 생성을 시작합니다. 장면 준비를 기다리지 않고 그림일기만 저장할 수도 있습니다.
5. 초안 글·그림·날씨를 확인한 뒤 **이대로 저장**을 누릅니다. 저장 전 확인 화면에서는 글을 직접 편집하지 않으며, 저장 후 **일기 수정**에서 고칩니다.
6. **달력**에서 저장한 그림일기와 4컷 결과를 다시 봅니다. 그림이나 만화의 저장이 실패했다면 화면의 저장 재시도 안내를 따릅니다.
7. 고민이 있다면 방의 **창문**에서 우냥이와 이야기합니다. 지난 기록에서 진행 중인 대화를 이어 쓸 수 있습니다.

### 기다림·저장·재시도 안내

- 4컷의 결과가 불명확하거나 처리 중이면 **‘진행 상태 확인’**으로 기존 요청을 조회합니다. **‘이 컷만 다시 만들기’**는 서버가 재시도를 허용한 컷에 표시됩니다.
- 그림 업로드가 실패하면 같은 일기와 그림으로 **‘그림 저장 다시 시도’**를 사용합니다. 성공 전까지 완료로 처리하지 않습니다.
- **저장 전 일기 대화와 그리는 중인 그림은 새로고침 뒤 복구되지 않을 수 있습니다.** 저장을 마친 뒤 페이지를 닫아 주세요. 우냥이의 진행 중인 상담 이어쓰기와는 별도 흐름입니다.
- 세로 화면에서도 일기를 작성·조회할 수 있습니다. 가구·장식 표시와 배치는 가로 화면에서 제공합니다.

## 구성과 기술

```text
FE: 화면·텍스트 대화·Canvas 그림·달력·방
  ├─ Supabase Auth: 회원가입·로그인
  └─ BE API: 인증·소유권·기록·재화·4컷 작업 관리
       ├─ Supabase PostgreSQL / Storage: 데이터·이미지 보관
       └─ AI 서버: 질문·일기 초안·장면·이미지·우냥이 응답 생성
```

| 영역 | 사용 기술과 역할 |
| --- | --- |
| FE | HTML·CSS·JavaScript, Canvas API, Supabase JavaScript SDK. `index.html`과 정적 자산으로 실행합니다. |
| BE | Python, FastAPI, Pydantic, HTTPX, Pillow. 회원별 API·DB/Storage 연동·AI 호출과 4컷 worker를 담당합니다. |
| AI | Python, FastAPI, Groq API, Cloudflare Workers AI의 FLUX.1 schnell, RapidOCR·ONNX Runtime. 생성과 이미지 문자 처리를 담당합니다. |
| 데이터 | Supabase Auth·PostgreSQL·비공개 Storage. FE에 서버 전용 Secret key나 AI 공급자 키를 넣지 않습니다. |
| 호스팅 | FE는 Cloudflare Pages, BE·AI는 별도 Docker 통합 구성으로 Render에 배포합니다. |

백엔드 기준 주소는 `https://today-and-near-api.onrender.com/`입니다. 루트(`/`)에는 웹 화면이 없어 404를 반환하며, [상태 확인](https://today-and-near-api.onrender.com/health)과 [API 문서](https://today-and-near-api.onrender.com/docs)를 이용할 수 있습니다.

## 로컬 실행

별도 npm 설치나 빌드 과정이 없는 정적 FE입니다. PowerShell에서 실행하는 예시입니다.

```powershell
git clone https://github.com/woowangthon/WOOWANGTHON_TEAM_22_FE.git
cd WOOWANGTHON_TEAM_22_FE
Copy-Item config.example.js config.js
```

1. [config.example.js](config.example.js)를 복사한 `config.js`에 개발 환경의 값을 입력합니다. `config.js`는 Git에서 제외됩니다.

   | 설정 이름 | 내용 |
   | --- | --- |
   | `API_BASE` | 실행할 BE의 주소. 로컬 BE 기본 주소는 `http://127.0.0.1:8000`입니다. |
   | `SUPABASE_URL` | 개발용 Supabase 프로젝트 주소 |
   | `SUPABASE_PUBLISHABLE_KEY` | 해당 프로젝트의 공개용 Publishable key |
   | `TIMEOUT_MS` | 선택 설정. 요청 종류별 제한시간은 예시 파일의 주석을 참고합니다. |

2. [AI README](https://github.com/woowangthon/WOOWANGTHON_TEAM_22_AI#readme)와 [BE README](https://github.com/woowangthon/WOOWANGTHON_TEAM_22_BE#readme)에 따라 서버를 각각 실행합니다. AI의 mock 모드는 대화 계약 확인용이며 실제 이미지나 실제 모델 응답을 생성하지 않습니다. 회원 인증·기록 저장에는 별도 개발용 Supabase 설정이 필요합니다.
3. VS Code **Live Server** 등 정적 서버를 포트 **5500**으로 실행하고 `http://127.0.0.1:5500` 또는 `http://localhost:5500`으로 접속합니다. BE의 `ALLOWED_ORIGINS`에 같은 주소가 있어야 합니다. 파일을 직접 여는 방식 대신 HTTP 서버를 사용합니다.

### 파일과 연동

| 경로 | 내용 |
| --- | --- |
| [index.html](index.html) | 방·일기·4컷·우냥이·상점 화면, 스타일과 API 연동 |
| [config.example.js](config.example.js) | 환경별 FE 설정 양식 |
| [assets/](assets/) | 아이콘·가구·마스코트·테마·나무 자산과 사용 안내 |

인증된 API 요청에는 Supabase access token을 전달합니다. 일기·4컷·상담은 BE가 발급한 ID와 버전을 사용하며, 결과 불명 시 기존 요청을 조회합니다. 회원이 바뀐 뒤 도착한 이전 요청의 응답은 화면에 반영하지 않습니다. 상세 API 계약과 스키마 재현 자료는 BE 저장소에서 관리합니다.
