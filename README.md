# WOOWANGTHON_TEAM_22_FE

## 오늘, 그리고

AI와 대화하며 하루를 돌아보고, 직접 그린 그림으로 그림일기를 완성하는 웹 서비스입니다.
방 안의 책장과 달력을 눌러 일기를 쓰고 다시 볼 수 있습니다.

현재는 빌드 과정 없이 `index.html` 한 파일로 동작합니다. 브라우저에서 파일을 열면 바로 실행됩니다.

## 사용 흐름

1. 방 화면에서 책장("오늘의 일기 쓰기")을 누른다.
2. 책이 펼쳐지면 AI와 오늘 있었던 일을 이야기한다.
3. "대화 끝내기"를 두 번 눌러 대화를 마친다.
4. 스케치북이 열리면 그림을 그리고 날씨를 고른 뒤 "그림일기 완성"을 누른다.
5. 달력이 열리고 오늘의 그림일기가 자동으로 펼쳐진다.
6. 나중에 달력("일기 확인")에서 날짜를 눌러 그림일기를 다시 본다.

## 기능

### 방 (메인 화면)
- 창문, 소파, 화분, 액자, 책장, 벽시계, 달력으로 꾸민 방 일러스트
- 화면 크기에 맞춰 확대/축소되는 고정 레이아웃 (스크롤 없음)
  - PC 1440×900, 모바일(세로) 600×1000 기준
- 책장 옆 "오늘의 일기 쓰기", 달력 옆 "일기 확인" 안내 문구
  - 오늘 일기를 완성하면 책장 문구가 "오늘의 일기 수정하기"로 바뀜
- 실제 현재 시간으로 움직이는 벽시계
- 로그인 / 회원가입 창 (화면과 입력값 검증만 있음)

### 책장 → AI와 대화
- 책장을 누르면 표지가 넘어가며 책이 펼쳐지고, 오른쪽 쪽에 채팅 화면이 나옴
- Enter로 전송, Shift+Enter로 줄바꿈, 한글 조합 중 전송 방지
- AI가 답변하는 동안 입력 중 표시
- "대화 끝내기" 버튼은 두 번 눌러야 종료 (3초 안에 다시 누르지 않으면 취소)
- 일기는 하루에 한 권만 작성
  - 오늘 일기를 완성한 뒤 책장을 다시 누르면 같은 일기를 수정 모드로 엶
  - 이전 대화를 이어서 할 수 있고, 스케치북에 전에 그린 그림과 날씨를 불러옴

### 스케치북 (그림 그리기)
- 이중 스프링 철이 달린 스케치북 모양의 창
- 색 16가지: 검정, 무지개 7색, 기본 8색(흰색, 회색, 갈색, 분홍, 하늘색, 연두, 살구색, 황토색)
- 드래그하는 막대로 굵기 조절 (1~60)
- Windows 그림판을 참고한 브러시 7종
  - 브러시, 서예 브러시, 에어브러시, 크레용, 마커, 연필, 수채화 브러시
- 지우개, 되돌리기, 모두 지우기
- 날씨 선택: 맑음, 흐림, 눈, 비
- 마우스와 터치 모두 지원, 화면 크기에 맞춰 스크롤 없이 한 화면에 표시

### 달력 → 그림일기 보기
- 벽의 달력을 누르면 화면 가운데로 확대됨
- 완성한 그림일기가 있는 날짜에 책 아이콘 표시
- 날짜를 누르면 그 날의 그림일기가 펼쳐짐
- **1쪽: 그림일기장 양식**
  - 년 / 월 / 일 / 요일
  - 날씨 (고른 날씨에 동그라미 표시), 이름
  - 스케치북에서 그린 그림 (스케치북과 같은 3:2 비율)
  - 밑줄 형태의 일기 글 칸
- **2쪽: 4컷 만화**
- PC는 두 쪽을 한 번에, 모바일은 한 쪽씩 넘겨 봄 (버튼, 책 클릭, ←/→ 키)
- "대화 기록 보기": 그 일기를 쓸 때 AI와 나눈 대화를 읽기 전용 창으로 보기
- "이 책 지우기": 한 번 더 눌러야 삭제

### 공통
- 키보드 조작: Enter/Space로 열기, Esc로 열린 창을 순서대로 닫기
- 화면이 닫히는 애니메이션 중에도 바로 다른 곳을 누를 수 있음
- 글자 선택과 그림 끌기(드래그) 방지 (입력칸 제외)
- `prefers-reduced-motion` 설정 시 애니메이션 제거

## 데이터 저장

- 그림일기는 브라우저의 `localStorage`에 날짜별로 저장됩니다. (`oneul-diary-YYYY-MM-DD`)
- 페이지를 새로 열 때마다 저장된 기록을 모두 지우고 빈 상태로 시작합니다.
- 저장되는 내용: 대화 기록, 그린 그림(이미지), 날씨, 작성 완료 여부

## 아직 연결되지 않은 기능

아래 기능은 화면과 자리만 만들어져 있습니다. 표시된 함수나 데이터만 채우면 화면에 반영됩니다.

| 기능 | 지금 상태 | 연결 방법 |
|---|---|---|
| AI 대화 답변 | "AI 답변 기능은 아직 준비 중이에요." 표시 | `getAIReply(message)`가 답변 글을 돌려주도록 구현 |
| 일기 글 (1쪽 밑줄 칸) | 비어 있음 | AI가 정리한 일기 글을 책의 `diary`에 저장 |
| 4컷 만화 (2쪽) | 점선으로 된 그림 자리 | 그림 주소 4개를 책의 `comic`에 저장 |
| 이름 (1쪽) | 비어 있음 | 로그인 후 사용자 이름을 책의 `name`에 저장 |
| 로그인 / 회원가입 | 항상 "준비 중" 안내 | `login()`, `signup()`이 결과를 돌려주도록 구현 |
| 달력 | 2026년 11월로 고정 | 다른 달로 이동하는 기능 추가 필요 |
