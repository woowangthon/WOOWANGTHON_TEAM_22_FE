- 라이선스: MIT — 원문 [../LICENSE-fluentui-emoji.txt](../LICENSE-fluentui-emoji.txt). 배포 시 이 고지 유지
- 색 상속: 없음. 모든 색이 SVG 안에 고정값으로 들어 있고 `currentColor`를 쓰지 않음 (테마 토큰으로 색이 바뀌지 않음)
